Incident Report Log - Q1 Infrastructure Operations

Incident ID: INC-401
Timestamp: 2026-02-14 10:15:00 UTC
Target Host: worker-node-east-01
Symptom: CPU usage sustained at 98% for 12 consecutive minutes.
Root Cause: Runaway backtracking regex parsing in document element splitter during large markdown table processing.
Resolution: Deployed patched linear regex filter and restarted ingestion worker daemon within 8 minutes.

Incident ID: INC-402
Timestamp: 2026-02-14 10:45:00 UTC
Target Host: worker-node-east-02
Symptom: Memory usage sustained at 96% for 15 consecutive minutes.
Root Cause: Unbounded PDF binary stream buffering in memory during multi-gigabyte document uploads.
Resolution: Implemented temporary file streaming on disk and capped maximum in-memory allocation to 512 MB.

Incident ID: INC-501
Timestamp: 2026-03-01 04:20:00 UTC
Target Host: api-gateway-01
Symptom: Ingress network packet drop rate exceeded 4.5% during morning peak traffic.
Root Cause: HTTP client connection pool exhaustion under concurrent client polling requests.
Resolution: Increased maximum client connection pool size from 100 to 500 connections in uvicorn configuration.

Incident ID: INC-502
Timestamp: 2026-03-01 04:55:00 UTC
Target Host: api-gateway-02
Symptom: Ingress network packet drop rate exceeded 7.2% during secondary burst.
Root Cause: Ephemeral port exhaustion on external public network interface under persistent keep-alive connections.
Resolution: Tuned tcp_tw_reuse kernel network parameter and horizontally scaled second gateway pod replica.
